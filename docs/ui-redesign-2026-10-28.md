# 生活管家 · UI / 交互重设计提案

> 2026-10-28 · 状态：提案，未上线
> 目标用户：年轻情侣 · 关键词：灵动、活泼、有趣、奇思妙想
> 原则：基础功能全部保留；先改体验结构，再改皮。

---

## 0. 诊断

现在这个 App 是**两个产品住在一个壳里**：

- 聊天是微信克隆：深色、通栏、设置清单；
- 小屋是宫崎骏式的暖光房间：二狗、木桌、窗、账本。

两边都成立，但互不认识。聊天不承认小屋，小屋也不参与聊天。管家只是一个带绿点的头像：没有身体、没有位置、没有脾气。于是“可爱”只是装饰，“功能”只是一张清单。

**核心判断：小屋已经是全 App 最好看的东西。不要重画它，要让聊天住进去。**

---

## 1. 核心概念：纸上小屋

一句话：**你们住在一间会记事的小屋里；聊天，是铺在书桌上的那本摊开的信簿。**

- **小屋 = 家**（远景，本体）
- **信簿 = 聊天**（近景，每天写字的地方）
- **二狗 = 管家在小屋里的身体**（第三个成员，不是工具）

核心动作不是“切页”，是 **落座 / 起身**：

- 左滑：信簿落回桌面，缩小、微斜，小屋亮起来；
- 点信簿：镜头俯冲到纸面，信簿铺满屏。

保留现有左滑手势、24px 边缘、96px 阈值；只换“它意味着什么”。

### 设计原则

1. **家先于功能**：每个功能在屋里有个位置，不是设置里的一行。
2. **管家有身体，也有分寸**：会看你、会打盹、会叼提醒；但不挡字、不催命。
3. **每句话都留得下**：任何一句话/一张图，都能一键钉到回忆墙。
4. **一眼会用，三秒会笑**：聊天还是聊天；惊喜只放在缝里。
5. **暖，但不腻**：80% 安静，20% 惊喜；不做满屏贴纸、紫色 AI 渐变、玻璃拟态。

## 2. 空间结构（IA）

```
小屋（远景）
├─ 书桌上的信簿 ......... 聊天（近景）
├─ 窗户 ................. 今日明信片
├─ 书架上的书 ........... 账本
├─ 闹钟 ................. 提醒
├─ 小相框 ............... 组件
├─ 墙上画框 ............. 回忆墙
├─ 二狗 ................. 管家面板
└─ 桌上钥匙 ............. 我们的家
     ├─ 住户 / 邀请
     ├─ 小屋（名字/纪念日/光线/信纸/便签）
     ├─ 管家（能力/记忆/性子）
     ├─ 阁楼（ARCH，内容不动）
     ├─ 工作间（模型/检查更新/诊断）
     └─ 门厅（账号/通知/隐私/退出）
```

### 导航规则

| 入口 | 去哪里 | 备注 |
|---|---|---|
| 聊天左滑 | 小屋 | 保留跟手 + 96px 阈值 |
| 点信簿 | 聊天 | 镜头俯冲 |
| 点窗 | 今日 | 明信片 |
| 点书架书 | 账本 | 新的 v60 组件，不覆盖 v59 |
| 点闹钟 | 提醒 | 现有 API |
| 点小相框 | 组件 | 现有 workshop |
| 点墙上画框 | 回忆墙 | 新屏 |
| 点二狗 | 管家面板 | 底部 sheet |
| 点钥匙 | 我们的家 | 原设置，重新分组 |
| 右滑消息 | 引用 | 保留 |
| 长按消息 | 钉墙/提醒/记账/引用/复制/删除 | 新增 |
| 安卓返回 | 关最上层 | 新屏仍报 `settings` |

**不做**：不做汉堡菜单、不做底部 tab bar、不做聊天气泡里的机器人图标。房间里的东西就是导航。

## 3. 六个必须做对的交互

### 3.1 落座 / 起身

- 聊天和小屋共用一个 `transform-origin`（信簿中心）。
- 聊天 → 小屋：`scale 1 → .42`、`rotate -1.2°`、位移到桌面；小屋 `scale 1.04 → 1`；620ms，`cubic-bezier(.22,1,.36,1)`。
- 可中断：松手/反向滑动按当前进度回弹；低端机降级为 180ms 交叉淡入。
- 只动 `transform/opacity`，过渡期间才加 `will-change`。

### 3.2 二狗在纸角

- 聊天里只露头和一只爪子，位置在页面右上角，**不挡字、不挡发送键**。
- 状态：打盹 / 看你打字 / 看新消息 / 叼提醒 / 伸懒腰；6s 简化循环，页面隐藏即暂停。
- 点一下：小反应（耳朵动/呼噜）；长按：管家面板；拖拽：可以把它放到纸的另一个角，位置记住。
- 屋里是完整二狗，24s 循环；聊天里是“探头”版，二者是同一只。
- 可以“让它睡一会儿”，所有主动提示静音。

### 3.3 今日明信片

- 入口：点窗；或聊天顶部的小太阳；或从聊天顶部下拉。
- 结构：一张撕边明信片，猫爪邮票、当天邮戳、管家 3 行短句、1 个问题、2 个动作。
- 数据只来自本地：提醒、账本、照片/回忆、今天是几号；**不承诺天气**（无外网）。
- 每天只生成一次，缓存；模型失败用模板兜底，绝不阻塞打开。
- 动作：记一笔 / 定提醒 / 写一句 / 钉到墙上（最多 2 个主按钮）。
- 文案示例：
  - “今天没有大事。这很好。”
  - “你们有 1 件小事：19:30 关火。”
  - “昨晚那张照片，我放在窗台上了。”
  - “今晚问你们一个：第一次一起吃饭，吃的是什么？”

### 3.4 把这句话收进回忆

- 长按消息 → 文具托盘：引用 / 钉到墙上 / 变成提醒 / 记一笔 / 复制 / 删除。
- “钉到墙上”：消息变成拍立得，管家问一句“给它写个什么？”（可跳过），卡片飞到墙上；可撤销。
- “记一笔”：若消息里有金额/店名，管家建议“火锅 ¥128，记上？”；一键确认，不自动记。
- “变成提醒”：有明确时间/动作时建议；低频、可关。
- 这是把聊天变资产的核心动作，也是管家“有用”的证据。

### 3.5 工具扇

- 点“+”不是弹网格，是从按钮向上展开 5 个实物：账本、闹钟、小相框、照片、文件。
- 拖到某个物件松手即选中；也可以直接点。
- 保留现有拍照/图片/文件/语音/表情全部能力；工具扇是加法，不是替换。
- 每个物件有独立形状和颜色，不靠文字解释。

### 3.6 昼夜光线

- 按本地时间：晨光 6–11 / 午后 11–17 / 黄昏 17–20 / 夜灯 20–6。
- 小屋用 CSS 叠色 + 灯光渐变，400ms 淡入；聊天纸微微变暖/变冷，正文对比度不变。
- 夜灯是暖黑 + 台灯黄，不是冷蓝黑。
- 可手动“开灯/关灯”；主题仍是每人自己的，屋里装饰是共享的。
- 异地：同一间屋，两地的天色（各看各的窗外）。

## 4. 视觉系统：暖光纸屋

### 4.1 色彩

从 flat-room.svg 直接取色，聊天向小屋靠拢：

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#FBF3E3` | 信纸底 |
| `--paper-2` | `#F4E8D2` | 次级纸/卡片 |
| `--ink` | `#3A2E28` | 正文 |
| `--ink-2` | `#6B5E4E` | 次级文字 |
| `--line` | `#E2D3BC` | 分隔/纸边 |
| `--wood` | `#A9714B` | 桌面/边框 |
| `--terra` | `#C9553D` | 主强调/印章 |
| `--honey` | `#E8B04B` | 暖光/高亮 |
| `--moss` | `#6F8B5E` | 成功/植物 |
| `--sky` | `#8FB7C8` | 信息/窗外 |
| `--plum` | `#7B4E68` | 夜晚/点缀 |
| `--blush` | `#E8B4B4` | 窗帘/情感 |
| `--night` | `#1C1A1F` | 夜灯底 |
| `--lamp` | `#F2C879` | 夜灯 |

- 正文 `--ink` on `--paper` ≈ 11:1；次级 ≈ 5.5:1。
- `--terra` 只用于大字号/图标；正文红用 `#A8432F`。
- 夜灯下正文 `#F4E9D8` on `#2A262C` ≈ 12:1。
- 语义：成功 moss、提醒 honey、危险 terra、信息 sky；不用纯红/纯绿。

### 4.2 字体

- 标题/大数字：得意黑（Smiley Sans）子集，26/34/44，轻微斜切；只用于固定 UI 字与标题；用户内容回退系统字。
- 正文：系统 PingFang SC / Noto Sans SC，15–16px，行高 1.65。
- 管家短句：霞鹜文楷子集，13–15px；只用于明信片/边注，不用于长聊天。
- 字体是加分项，不是前提：没有字体时，靠纸、旋转、猫和留白，仍然成立。
- 不为了字体牺牲首屏；子集化，缓存，缺字回退。

### 4.3 形状与材质

- **Die-cut**：3px 纸白外描边 + 1px 同色线；用于贴纸、头像、照片、今日卡。
- 圆角 10/16/22/28；气泡 1.2em；不做统一 16px 卡片网格。
- 摆放旋转 -1.5°–1.5°；文字多的卡片不超过 1°。
- 纸阴影：`0 1px 0 rgba(70,45,20,.06), 0 8px 24px rgba(70,45,20,.10)`。
- 灯光是径向暖光，不是投影。
- 纸纹 3% 叠加；正文下方不加纹理；低端机可关。

### 4.4 图标

- 2px 圆头手绘线，24 网格；统一进 `ICO`，不散落内联 SVG。
- 新增：门、钥匙、太阳、月亮、书、钟、画框、架子、爪印、图钉、收据、梯子、齿轮、明信片、撕边、引用、回忆。
- 房间里不用图标——物件就是图标；图标只用于按钮和列表。

### 4.5 动效

| Token | 值 | 用途 |
|---|---|---|
| `--t-micro` | 120ms | 按压/勾选 |
| `--t-ui` | 240ms | 常规 |
| `--t-space` | 420ms | 纸的展开 |
| `--t-dolly` | 620ms | 落座/起身 |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 进入 |
| `--ease-in` | `cubic-bezier(.4,0,1,1)` | 退出 |
| 弹簧 | 220/26、320/30 | 贴纸/拖动 |

- 消息：下落 8px → 落定；发送：折纸飞出；贴纸：撕下 → 旋转 → 贴住；照片：白片显影 600ms。
- 猫：呼吸 3.6s、眨眼 4–7s、尾巴 2.8s、被叫时 200ms 抬头；不可见即暂停。
- 不做滚动视差；不做无限循环的背景动画；尊重 `prefers-reduced-motion`。

### 4.6 声音与触感

- 3 个 UI 声：纸（发送）、啵（贴纸）、铃（提醒）。
- 可选环境音：雨/柴火；默认关；共享开关。
- 触感：发送轻、贴纸软、长按硬；没有原生桥就 no-op。
- 不自动播放；必须用户手势后启用。

### 4.7 夜灯

- 不是反色，是关灯：暖黑、台灯黄、纸变深牛皮纸、猫眼反光。
- 正文对比度 ≥ 7:1；所有状态不只靠颜色。

### 4.8 无障碍

- 44×44 最小热区；房间物件有隐形热区和 `aria-label`。
- 支持 130% 字体；正文不压图；纸纹不压字。
- 关键路径都有可见按钮，手势不是唯一入口。
- 屏幕阅读器：房间物件读作“书桌上的信，打开聊天”；猫有 alt；明信片有文字版。

## 5. 逐屏

### 5.1 登录 / 入住

- 一扇关着的门，暖光从门缝漏出；“推门”后才出现登录表单。
- 第一次：给小屋起名 → 选一盏灯（主题）→ 配一把钥匙（邀请）。
- 管家只出现 3 句： “我是管家。你们忙，我记得。” 不做功能轮播。
- 老用户升级：管家留一张便条：“屋子收拾了一下。你的东西都在原来的抽屉里。” 一键“看看”。

### 5.2 小屋（`#workshop` 改造）

- 用现有 flat-room.svg；不重画。
- 桌上摊开的书 = 聊天入口；书签是未读红丝带。
- 窗 = 今日；书架 = 账本；闹钟 = 提醒；小相框 = 组件；墙上画框 = 回忆；二狗 = 管家；桌上黄铜钥匙 = 我们的家。
- 房间会“长”：第一次记账，账本出现在架上；第一张回忆，照片墙多一张；第一个提醒，闹钟开始走。没有升级弹窗，只有物件悄悄出现。
- 新用户空屋：纸箱、空桌、一盏灯、猫坐在箱子上；“还差一把椅子。先贴张照片？”
- 透明椅子保留：它不催人，只是留着。
- 第一次进屋有手绘小标签（信/今日/账本/提醒/照片墙/管家/钥匙），第二次撤掉；界面不写说明书。

### 5.3 聊天（`#chat` 换皮）

- 信簿摊开的一页：米色纸、极淡横线、左侧红边线、右上角书签丝带。
- 顶部不是通栏：组名手写体 + 管家状态（“在煮茶/在擦桌子/在打盹”）；**删掉“窥屏”**。
- 日期是一条和纸胶带，滚动时吸顶。
- 三种声音三种形状：
  - 对方：纸白便签，苔绿细线；
  - 自己：蜂蜜/陶土便签，深墨字；
  - 管家：不装气泡，写在页边（边注），长内容才用一张折起来的纸条。
- 照片是拍立得，显影；语音是撕边波形；文件是回形针夹纸；组件是夹在纸上的小票/相框。
- 输入区是桌面笔盘：麦克风、文字、贴纸、+、发送；二狗坐在右缘，不挡发送。
- 滚动到底：右侧红丝带书签，可拖。
- 保留：引用、@、待发附件、图片/文件/语音、19 张表情、气泡皮肤、灯箱保存。
- 长按菜单：文具托盘（见 3.4）。

### 5.4 今日

- 明信片全屏/半屏；撕边、猫爪邮票、邮戳、管家 3 行、1 个问题、2 个动作。
- 可翻面看“今天的小事”清单；可收藏到回忆墙。
- 空状态：“今天没有大事。这很好。”
- 不推送天气；不制造焦虑；每天最多 1 次。

### 5.5 工具

- **账本**：新 v60 组件，纸账本；左页本月/右页最近；“我请/他请/AA/公账”；不评价、不排名、不做个人流水。保留 v59，不覆盖。
- **提醒**：黄铜闹钟；今天/明天时间轴；共享/个人；到点猫叼纸条。
- **组件**：架上小相框；最近 3 个 + “全部”进 workshop；权限/票不变。
- **工具扇**：从 + 展开，拖拽选择。

### 5.6 回忆墙

- 画框进入；软木板 + 和纸胶带 + 拍立得；按月份滚动，不做无限流。
- 每条：图/文、题注、日期、谁钉的；可保存到手机、可删（可撤销）。
- 空状态：第一天的拍立得 + “第一张，从今天开始。”
- 今日卡里偶尔出现“去年的今天”，不推送。
- 后端新增 `memories` 表；先只读“本周回顾”验证，再上可钉的墙。

### 5.7 管家面板

- 从二狗长按/点击打开底部 sheet：
  - 它会什么：记账/提醒/组件/回忆/今日卡——每个都是可点按钮，不是说明文字。
  - 它记得：列出 `group_memory`，可看、可改、可“忘记”。
  - 它的性子：温和/损友/少话三档 + 高级（工作间）。
  - 它的身体：猫的配饰、声音、主动建议开关、让它睡一会儿。
- 不在情侣界面放模型/提示词编辑器；那些进工作间。
- 管家是**屋子共有的**，不是任何一个人的私人助手；不告密、不站队、不读私聊（本来也没有）。

### 5.8 我们的家（`#settings` 重组）

- 黄铜钥匙打开；顶部是两位住户 + 小屋名字 + 入住日（可选）。
- 分组：
  - 住户：我的 / 对方 / 邀请（钥匙）
  - 小屋：名字 / 纪念日 / 光线 / 信纸 / 便签
  - 管家：能力 / 记忆 / 性子
  - 阁楼：ARCH（内容不动）
  - 工作间：模型 / 检查更新 / 诊断（管理员）
  - 门厅：账号 / 通知 / 隐私 / 退出当前空间 / 退出登录
- 原有 10-24 定的顺序全部保留，只是分进房间；不删“检查更新/邀请码/模型”。

### 5.9 工作间 / 阁楼

- 工作间：安静、平实、等宽字、蓝图/洞洞板；**猫不进来**。模型池、更新、诊断。
- 阁楼：ARCH 原样保留五个 tab；只在屋里加一个梯子入口，不改内容、不改 `cc_arch_v3` / `cc_arch_build_v1`。

## 6. 用户心理

### 为什么这对情侣成立

1. **“我们的地方”**：情侣不缺一个聊天工具，缺一个能证明“我们是一个单位”的地方。小屋、门、钥匙、猫、账本，都是“我们”的物证。
2. **第三个人，但不是第三者**：共有管家提供中性话题和帮助，不站队、不告密；它是室友，不是裁判。
3. **记忆是护城河**：聊天会滚走，回忆墙不会。人们为“已经一起留下这么多”而留下。
4. **不对等的参与**：一方可能更爱布置，另一方只想说话。设计要允许“只聊天也完整”，不做“你三天没来了”的内疚。
5. **仪式胜过推送**：早安明信片、夜里关灯、周末小报；少而可预期，才值得期待。
6. **峰值-终点**：一天最后 10 秒决定记忆。关灯、猫睡、管家一句“灯我关了”，是设计的峰值。

### 不做

- 不做已读回执、在线状态、恋爱分、连续打卡。
- 不做信息流、社交关系、公开主页。
- 不做“喂猫/养宠物”的日常劳动，不制造愧疚。
- 不做每屏都撒彩带；不做紫色 AI 渐变；不做玻璃拟态。
- 不用“宝贝/亲亲”的客服腔；管家是干燥、会观察、偶尔损一句的室友。
- 不在情侣界面暴露模型/密钥/内部配置。

### 管家的语气（示例）

| 场景 | 文案 |
|---|---|
| 空聊天 | “我先去烧水。你们聊。” |
| 提醒 | “三分钟后关火。我盯着。” |
| 记账 | “记上了：火锅 ¥128。这顿算谁的？” |
| 早安 | “早。今天你们有 1 件小事。” |
| 夜里 | “今天说了 42 句话，笑了 7 次。灯我关了。” |
| 出错 | “我没接上话。再说一遍？” |
| 回忆 | “这张，要钉到墙上吗？” |
| 邀请 | “配一把钥匙给他/她。” |
| 离线 | “门开着，网断了。等会儿再试。” |

## 7. 落地

### 保留

- 所有基础功能：登录/初始化、文字/图片/文件/音频/语音/表情、引用、@、待发附件、灯箱保存、设置、资料、管家、workshop、组件预览、主题、背景、气泡皮肤、模型管理、邀请、检查更新、退出、ARCH。
- 现有素材：flat-room.svg、二狗、19 张表情、气泡皮肤、三套主题、账本组件 v59。
- 现有手势：左滑 24px 边缘/96px 阈值、右滑引用、安卓返回键。
- 工程规矩：CRLF（`app.css`/`05-settings.js`）、`.ascreen` 作用域、`ICO` 单一来源、z-index 顺序、`_OTHER_SCREENS`/`__goBack`、静态不改不用重启。

### 改动

- 聊天视觉：微信 → 信簿。
- 导航：房间即首页；聊天是近景；设置进钥匙；管家进猫。
- 管家：身体、边注、能力面板、记忆透明。
- 工具：实物入口 + 工具扇 + 长按动作。
- 仪式：今日卡、夜灯、回忆墙。
- 主题：暖夜灯 + 昼夜光线。
- 文案：管家语气、微文案、无介绍性长文。

### 工程注意

- **不推翻 ID**：在现有 `#chat`/`#workshop`/`#settings` 上换皮加层；新屏只加 `#today`、`#memoryWall`、`#butlerSheet`。
- 新全屏子页仍报 `settings`，加入 `_OTHER_SCREENS`，`__goBack` 分支按 z-index 从大到小。
- 换皮不动 `#bgSet` 的上传数据；只改话术和外观。
- 气泡皮肤保留第八版 die-cut 头部；媒体气泡仍排除；只调配色，不破结构。
- 表情 19 张、面板不写字、URL 补 `/static`、唯一清单 `stickers.json`。
- 账本新建 v60，不覆盖 v59；库行 `data_json` 一起复制。
- 小屋保持 900×1600 + `slice`；热区按桌面透视线量，不目测；每个热区 44px。
- 3D room（947KB）不作为默认；平房 38KB + CSS 足够。
- 房间 SVG 静态；动效只动 transform/opacity；页面隐藏暂停猫。
- 回忆墙是唯一要动数据库的新功能：先 `.backup` 快照，再迁移；不 `cp`。
- 今日卡缓存每天一次；模型失败用模板；不阻塞。
- 回忆墙图片缩略图/懒加载；账本 iframe 打开才加载。
- 字体子集化可选；没有字体也要成立。

### 分期

| 阶段 | 内容 | 时间 |
|---|---|---|
| P0 | 风格样张 + 聊天/小屋/今日/管家四屏静态原型 + 落座动效 | 3–4 天 |
| P1 | 信簿聊天 + 小屋落座 + 二狗 + 导航；开关可回旧版 | 1 周 |
| P2 | 今日卡 + 工具扇 + 账本/提醒/组件换皮 + 管家面板 + 我们的家 | 1 周 |
| P3 | 回忆墙（DB）+ 夜灯/昼夜 + 夜聊 + 声音/触感 + 无障碍 | 1–2 周 |
| P4 | 周末小报、盖章反应、猫配饰、打磨 | 持续 |

### 指标

- 北极星：**每周共同留下的东西** = 消息 + 回忆 + 账目 + 完成的共享提醒。
- 激活：24h 内双方各发 1 条 + 1 条回忆/提醒。
- 留存：D7/D30、今日卡打开率、夜聊完成率（可选）。
- 功能：工具扇使用、记账/提醒创建、回忆新增、管家面板打开、“忘记”使用（信任）。
- 质量：发送 p95 < 300ms、落座 60fps、崩溃率、对比度、零数据丢失。
- 护栏：通知退订率、日消息量不降、卸载不升；“像不像我们的家”定性回访。
- 不优化停留时长，优化“共同完成的小事”。

### 风险

| 风险 | 对策 |
|---|---|
| 太可爱，信任感下降 | 80/20；工作间安静平实；重要动作说人话 |
| 低端机卡顿 | 静态房间、只动 transform、降级交叉淡入、默认 3D 关 |
| 手势藏得深 | 物件可见、首次标签、所有关键路径有按钮 |
| 老用户不适应 | 管家便条 + 7 天“回旧版”开关 |
| 回忆墙迁移风险 | 先只读、先备份、可撤销 |
| 今日卡 AI 慢/贵 | 每天缓存、模板兜底、可关 |
| 隐私/告密感 | 不做已读/在线；管家共有；记忆可看可删；主动建议可关 |

## 8. 只做一件事

**先把聊天变成桌上那本摊开的信簿，把二狗放到纸角。**

这两个动作成了，整个 App 就成立了。其他的，都是在这两个动作上长出来的。

## 9. 参考系

这台机器没有外网，没法拉 Dribbble/Behance 的图；以下是设计经验里的参照系，不是“收集”来的链接：

- 动森：房间作为身份，日常节奏，物件即记忆。

- Linear / Notion：工作间/管理面的安静克制，和情侣面形成对比。
