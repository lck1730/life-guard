# 生活管家（life-guard）

「生活管家」的**全部代码**（服务端 + 安卓壳）。
仓库就放在运行目录 `/opt/lifeguard-chat`，**以服务器上的这份为唯一权威**，
通过服务器上的定时任务推送到 GitHub。

## 目录

| 路径 | 是什么 |
|---|---|
| `app/` | FastAPI 服务：登录/空间、群聊、媒体、模型网关、组件渲染 |
| `android/` | 安卓壳（WebView）源码；当前 versionCode 17 / 0.7.0 |
| `hermes/SOUL.md` | 群管家（每个空间一份）的身份与规矩，开通时注入 |
| `ui/` | 界面用到的静态素材 |
| `docs/` | 设计笔记 |

## 跑在哪

- `lifeguard-chat.service` —— 127.0.0.1:8730
- `lifeguard-chat-forward.service` —— 把 8730 转发到私有网络
- `hermes-gateway.service` —— 127.0.0.1:8642

## 不在这个仓库里

`data/`（数据库与媒体）、`var/`（组件、模型配置、上下文队列）、
`keys/`、`releases/`、`.env`、日志、缓存 —— 都已写进 `.gitignore`。

## 维护方式

- 从手机上的「远程CC」直接改服务器上的这份代码，改完提交。
- `life-guard-push.timer` 会定时把它推到 GitHub。
- **不要再从本地旧仓库部署覆盖服务器** —— 本地那份已经落后，
  曾经因此把服务器上的改动整个抹掉过一次（2026-10-22）。
