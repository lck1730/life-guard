# 表情包编号对照表（v1）

这份表和 `stickers.json` 是同一件事：`stickers.json` 是**程序读的**，
这里是**人看的**。改表情时两份一起改。

- 图片：`static/stickers/v1/<编号>.webp`（512×512）、`<编号>-t.webp`（160×160 缩略图）
- 消息里只存**编号**（`msg_type=sticker`、`content=编号`），显示时按编号找图
- **3xx 是管家的**（猫猫管家），管家只能发这一套；1xx / 2xx 是群友的
- 换图时新建 `v2/` 目录、改 `stickers.json` 的 `version` 和 `file` 路径，别原地覆盖
  （URL 带 `?v=` 是长期缓存，原地覆盖会让旧缓存一直显示旧图）
